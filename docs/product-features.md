# Finding 产品功能文档

> 面向团队新同学的产品功能全览。本文档描述**当前最新功能**，随代码同步更新。
> 技术实现细节见 `docs/design-manual.md`，领域术语见 `CONTEXT.md`。

---

## 1. 产品定位与角色

**Finding** 是山东理工大学校园社交平台，核心解决三类诉求：**看校园动态、找搭子一起玩、相亲交友**。

| 角色 | 能力边界 |
|------|----------|
| **游客** | 浏览动态/搭子/推荐（推荐需登录），可搜索；互动（点赞/关注/报名等）会弹登录框 |
| **未认证用户** | 登录后可用浏览、点赞、关注、编辑资料；发帖/评论/搭子/私信/相亲需先完成学生认证 |
| **已认证用户** | 全部功能 |
| **管理员** | 登录 `finding-admin`，负责审核、封禁、内容管理 |

## 2. 用户端功能详解

### 2.1 首页 / 校园动态

**信息流** 三个 Tab：
- **热门**：子排序支持「按浏览量 / 按点赞数 / 综合推荐」
- **最新**：按发布时间倒序
- **关注**：只看已关注用户（需登录）

**动态操作**：发布（≤5000 字 + 最多 9 张图 + 位置）、编辑、删除；点赞；两级评论与回复（一级评论 + 每条最多展示 3 条子回复）；动态详情含浏览量（1 小时窗口去重）、点赞数、评论数。

**内容安全**：发布走敏感词分类——命中拦截词直接拒绝（提示具体词）、送审词进入待审队列（仅作者可见，管理员后台过审）、干净内容直接发布。图片仅接受平台上传地址，后端校验数量/长度/来源。

**游客限制**：未登录仅可见前 5 条，登录后看全部。

### 2.2 找搭子

**9 大分类**：旅游 / 拼车 / 健身 / 学习 / 备考 / 运动 / 游戏 / 娱乐 / 其他。

**列表与排序**：按活动时间最近优先（自动过滤已过期）、或按距离最近（需授权定位，Haversine 计算）；支持关键词搜索、按地点/时间/是否有空位/是否匿名筛选。

**发布邀约**：分类 + 标题 + 描述 + 活动时间（本地时间，无时区偏移）+ 地点 + 人数上限（2-50）+ 可选匿名发布。

**参与流程**：
```
申请加入(可留言) → 发起人收到通知 → 通过/拒绝 → 申请人收到结果
满员后 → 进入候补队列 → 有人退出自动按申请顺序补位
```
- 名额通过**原子条件更新**防超卖；重复通过/拒绝/退出不会重复改名额。
- 地点脱敏：发起人和已通过成员看精确地点，其他人（含待审/被拒/匿名活动观众）只看到"报名通过后可查看集合地点"。
- 发起人可编辑/取消/停止报名；活动过期后不可报名。

### 2.3 相亲交友（鹊桥）

这是项目的特色模块，完整闭环：**推荐 → 申请 → 审批 → 会话 → 信息互换 → 情感简历**。

#### 2.3.1 推荐流（单卡滑动）
- 一次只推荐一个用户，卡片展示对方的照片 + 昵称/年龄/性别 + 学校/城市/距离 + 认证徽标 + 交友目标 + 自我介绍 + 匹配理由（同校/同城/已认证/兴趣相投/偏好同校等）+ 最近在线。
- **❤️ 爱心** → 直接发送聊天申请；**✖️ 叉号** → 标记不感兴趣换下一个。已申请/已跳过的人不会重复出现。
- **反馈闭环算法**：推荐排序会参考你的申请/跳过历史——常申请的学校/城市的人排更前，常跳过的类型被压低；新用户（无历史）优先推已认证、近期活跃的候选。权重可配置。

#### 2.3.2 我的卡片
用户可**自定义自己在别人眼里长什么样**：
- 展示项开关：照片 / 昵称 / 年龄 / 性别 / 学校 / 城市 / 距离 / 认证标识 / 交友目标 / 自我介绍 / 匹配理由 / 最近在线。
- 展示项分组为**多张卡片**：资料卡（主）+ 介绍卡 / 标签卡 / 活跃卡，可自由组合。
- 实时预览"别人视角里的我的卡片"，保存后推荐流按此裁剪字段（隐藏的项别人看不到）。

#### 2.3.3 聊天申请与审批
- 发起申请（可写备注，敏感词过滤）；对方加好友方式影响流程：`0=自动通过`（立即建会话）/ `1=需验证`（默认，通知对方审批）/ `2=不允许申请`。
- 待处理申请**同一方向唯一**；被拒/撤回后 **7 天冷却期**；待处理 7 天未处理自动过期。
- 我发出的 / 我收到的申请列表，支持按状态筛选（待通过/已通过/已拒绝/已撤回/已过期）与加载更多。

#### 2.3.4 信息互换与情感简历
- **信息互换**需**先建立聊天关系**（任一方向有已通过的聊天申请）。请求 → 对方同意 → 双方可查看对方的**情感简历**（详细资料）。
- **情感简历**：8 大板块（基础信息/自我画像/恋爱复盘/相处模式/生活规划/理想另一半/加分项/走心宣言 + 生活相册）。互换前对他人锁定，互换后解锁。

#### 2.3.5 相亲偏好
性别 / 年龄范围 / 最大距离 / 只看已认证 / 偏好城市 / 交友目标 / 资料完整度门槛，用于推荐候选过滤，含完整边界校验。

### 2.4 消息 / 聊天

**消息中心**两层：通知中心（未读角标）+ 私聊会话列表。

**通知类型**：点赞、评论、回复、关注、搭子申请/通过/拒绝、聊天申请/通过/拒绝、信息互换、系统消息。

**私聊**：
- 会话列表（置顶/免打扰/隐藏）；消息实时 WebSocket 推送（应用内即时）。
- 单聊由「相亲审批」建立，不能随意建会话（需先有聊天关系）。
- 已读回执、消息撤回、图片消息、聊天背景（可上传/预设）、清空聊天记录、隐藏会话、投诉。
- 聊天信息页：查找聊天记录（关键词搜索）、对方名片。

**群聊**：创建群、群信息、群成员、群内消息。

**聊天设置**（全局）：默认聊天背景、加好友方式、隐私（是否可被搜索 / 资料可见性）、相亲偏好。

### 2.5 我的 / 个人中心

- **资料卡**：头像、昵称、学校、签名、个人背景图；**统计三项**：关注（followingCount）/ 粉丝（followerCount）/ 好友（互关数），点击进入关注/粉丝/互关列表（可关注/取关）。
- **情感简历**入口。
- **菜单**：我的动态、我的点赞、我的圈子、历史记录、我的预约、订单、我的投诉、帮助与客服（FAQ/联系/指南/人工）、设置、关于我们。
- **设置**：聊天设置、加好友方式、隐私设置、相亲偏好、账号与安全。
- **学生认证**：提交真实姓名 + 学号 + 学校 + 学生证照片 → 管理员审核 → 通过解锁全部功能；被拒可查看原因重新提交。

### 2.6 搜索

聚合搜索用户（按昵称/学校）、动态、搭子。

## 3. 管理后台功能详解（finding-admin）

管理员用 `13800000000` 登录。左侧菜单按模块组织。

| 模块 | 功能 |
|------|------|
| **数据面板** | 用户数、今日动态、搭子数、待审核数等统计 |
| **用户管理** | 搜索用户、查看资料、封禁/解封 |
| **实名审核** | 待审/已通过/已拒绝 Tab；查看认证材料、通过/拒绝（附原因） |
| **动态管理** | 动态列表、查看、隐藏/删除；**动态审核**（待审内容过审/拒绝） |
| **评论管理** | 评论列表与删除 |
| **搭子管理** | 搭子列表、查看、取消/关闭；**搭子审核**（待审过审/拒绝） |
| **举报处理** | 查看举报、证据、封禁/结案 |
| **申诉处理** | 内容审核申诉的处理 |
| **聊天审计** | 私聊消息审计 |
| **违禁词管理** | 违禁词增删改（拦截/送审动作） |
| **群管理** | 群聊列表与成员管理 |
| **相亲推荐管理** | 推荐相关运营管理 |
| **公告 / 横幅** | 系统公告、首页轮播图的新增/编辑/排序 |
| **反馈** | 用户反馈工单处理 |

## 4. 核心业务规则速查

| 领域 | 规则 |
|------|------|
| 认证 | 发帖/评论/搭子/私信/相亲需实名认证；未认证只读 |
| 拉黑 | 双向任一方拉黑即生效：不能搜索/推荐/关注/申请/私信/看详细资料；隐藏双方已建会话；已互换资料不再可见；不删除历史消息 |
| 聊天申请 | 冷却 7 天、待处理唯一、7 天过期；审批后建唯一会话 |
| 信息互换 | 需先有聊天关系；同意后解锁对方情感简历 |
| 搭子名额 | 原子条件更新防超卖；满员进候补按序补位 |
| 地点脱敏 | 发起人/已通过成员见精确地点，其余模糊 |
| 推荐 | 基于申请/跳过历史的反馈闭环；游客不可见真实推荐 |
| 内容 | 动态/搭子走敏感词拦截+送审；图片仅平台地址 |
