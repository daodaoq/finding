# Finding 隐私政策

> 版本：v1.0　生效日期：2026 年　适用：Finding 平台（含用户端、管理后台）

感谢你使用 Finding。我们重视你的隐私，并致力于保护你在平台上的个人信息。本政策说明我们收集哪些信息、如何使用、如何保护，以及你享有的权利。

## 一、我们收集的信息

### 1. 注册与账号信息
- 手机号、登录密码（加密存储）、昵称。

### 2. 个人资料
- 头像、性别、生日、学校、学号、个性签名、所在城市、经纬度（用于距离计算）、交友目标、情感简历（自愿填写，含身高体重、MBTI、照片等）。

### 3. 认证信息
- 学生实名认证时提交的真实姓名、学号、学校、身份证正反面照片、学生证照片。认证材料仅用于身份核验，审核通过后仅保留必要信息。

### 4. 内容与互动信息
- 你发布的动态、评论、图片、搭子邀约；你的点赞、关注、收藏、浏览记录、相亲申请/跳过记录、聊天申请、信息互换、聊天消息等。

### 5. 设备与日志信息
- 设备型号、操作系统、IP 地址、访问时间、接口日志（用于安全风控与故障排查）。

### 6. 位置信息
- 仅在你在相亲推荐、搭子距离排序等功能中主动授权定位时获取，用于计算距离。不授权不影响基本使用。

## 二、我们如何使用信息

1. **提供核心功能**：登录、动态与评论、找搭子、相亲推荐、实时聊天、信息互换、情感简历。
2. **个性化推荐**：基于你的申请/跳过历史、资料与行为，优化相亲与内容推荐排序（详见推荐逻辑说明）。
3. **内容审核与安全**：敏感词过滤、图片安全审核、异常行为检测、封禁/风控，保障平台内容合规与用户安全。
4. **运营与客服**：处理反馈、投诉、申诉、账号问题。
5. **依法合规**：配合法律法规要求与监管。

## 三、信息的共享与披露

我们**不会向任何第三方出售**你的个人信息。仅在以下情形可能共享或披露：

1. 经你**明确同意**；
2. 法律法规、监管机关、司法机关要求；
3. 为保护 Finding、其他用户或公众的人身财产安全所必需；
4. 与提供服务所必需的第三方（如云存储、短信服务商）合作，且我们要求其按本政策保护你的信息。

## 四、信息的存储与保护

- 信息存储于中国境内服务器。
- 密码经 BCrypt 加密存储；传输采用 HTTPS 加密。
- 我们采取访问控制、数据加密、日志审计等措施防止未授权访问、篡改、泄露或丢失。
- 请妥善保管你的账号与密码，勿泄露给他人。

## 五、你享有的权利

1. **访问与更正**：在「我的—编辑资料」中查看与修改你的资料。
2. **注销账号**：在「我的—设置—账号与安全—注销账号」申请注销。注销后：你的账号资料被**匿名化**（昵称改为「已注销用户」、头像等清空），原手机号无法再登录；你发布的公开内容保留，但作者显示为「已注销用户」；聊天记录对另一方保留但你的昵称/头像消失；待处理的聊天申请与信息互换被取消。
3. **撤回授权**：随时可关闭定位权限、关闭「允许被搜索」等隐私设置。
4. **联系我们**：通过应用内「帮助与客服」或公布的联系方式，申请查询、更正或删除你的个人信息。

## 六、未成年人保护

Finding 面向**已满 18 周岁的在校学生**。我们不会故意收集未成年人的个人信息。若你未满 18 周岁，请勿使用本平台。

## 七、隐私政策更新

我们可能适时更新本政策。更新后将在平台内公布。重大变更将通过公告或弹窗提醒。你继续使用即视为接受更新后的政策。

## 八、联系我们

如对本政策或你的个人信息有任何疑问、投诉或建议，请通过应用内「帮助与客服」与我们联系。
